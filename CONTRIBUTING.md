# Contributing

Open an issue before substantial changes so product intent and protocol impact are explicit. Read `AGENTS.md` and the architecture decisions before coding.

Use a focused branch and Conventional Commits. Include tests for changed behavior, update public contracts and operational documentation, and run the verification matrix in `AGENTS.md`. Pull requests must explain the user outcome, trade-offs, failure behavior, and evidence. Never commit secrets, generated build output, or edited historical Flyway migrations.

By submitting a contribution, you agree that it is licensed under Apache License 2.0 and that you have the right to submit it.
