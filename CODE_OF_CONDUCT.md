# Code of conduct

Be respectful, specific, and constructive. Harassment, discrimination, threats, personal attacks, and publication of private information are not acceptable. Maintainers may edit or remove contributions and restrict participation when behavior harms the community. Report conduct concerns privately through the repository owner's GitHub contact channel.

This policy applies to repository spaces and public representation of the project. Enforcement should be proportionate, documented, and focused on restoring a safe collaborative environment.
