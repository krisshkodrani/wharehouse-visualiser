# Security policy

## Supported version

Only the latest tagged release receives security fixes. Report vulnerabilities privately through GitHub's security-advisory feature; do not open a public issue with exploit details.

## Deployment warning

The Compose stack is a local demonstration profile. It has shared development credentials and no authentication, authorization, TLS, rate limiting, broker ACLs, or independent functional-safety controls. Do not expose it to an untrusted network or use it to control physical equipment.

Reports should include the affected version, impact, reproduction, and any suggested mitigation. Maintainers will acknowledge a complete report within seven days and coordinate disclosure after a fix or documented risk decision.
